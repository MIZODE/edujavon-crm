## Project Overview: Edujavon CRM

### What It Is
A **Library Management CRM System** with:
- **Backend**: Node.js + Express + TypeScript REST API
- **Frontend**: React SPA with Vite
- **Database**: PostgreSQL via Prisma ORM
- **API Docs**: Swagger/OpenAPI (auto-generated by TSOA)
- **Unique Feature**: Telegram bot for user verification

### Tech Stack

| Backend | Frontend |
|---------|----------|
| Express 5, TypeScript 5.9 | React 18.3, Vite |
| Prisma 7 (PostgreSQL) | TanStack Query, React Router 6 |
| TSOA 7 (REST + Swagger) | shadcn/ui + Radix UI |
| Redis (caching) | Tailwind CSS, Recharts |
| JWT auth (access + refresh) | React Hook Form + Zod |
| Telegraf (Telegram bot) | Axios |

### Directory Structure

```
│   └── generated/    # Auto-generated code
└── Frontend/         # React app (port 8080)
    ├── src/components/ui/   # shadcn/ui (49 components)
    └── src/pages/           # Auth, dashboards
```

### Key Features
- Role-based access (10 roles: SUPER_ADMIN, OWNER, LIBRARIAN, USER, etc.)
- Telegram verification for registration
- Comprehensive library schema (books, copies, authors, rentals, fines, reservations)
- Soft delete pattern, Redis caching, file uploads

### To Run
```bash
# Backend
cd backend && npm run dev  # http://localhost:9090/api-docs

# Frontend
cd Frontend && npm run dev  # http://localhost:8080
```
